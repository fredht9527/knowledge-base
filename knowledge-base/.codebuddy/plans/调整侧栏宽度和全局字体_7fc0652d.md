## 产品概述

调整现有 AI 助手页面的左侧导航栏宽度，使其与控制台（知识库）页面的左侧导航栏宽度保持一致（240px），同时优化全局字体层级体系，提升整体视觉专业度。

## 核心需求

1. **侧栏宽度统一**：AI 助手左侧对话历史侧栏宽度从 220px 调整为 240px，与控制台知识库侧栏完全一致
2. **全局基础字号提升**：body 基础字体从 13px 提升至 14px
3. **字体层级调优**：对所有 UI 元素的字号进行专业级调优（按钮、输入框、标签、时间戳等），建立清晰的视觉层级
4. **视觉一致性**：确保所有侧栏折叠态宽度（52px）、样式过渡动画等保持一致

## 调整原则

- **L1 - 基础正文（消息文本、输入框等）**：14px
- **L2 - UI 控件（按钮、标签、搜索框等）**：13px
- **L3 - 辅助信息（过滤标签、空状态、思考过程）**：12px
- **L4 - 次要元数据（时间戳、文件大小、编辑提示）**：11px
- 大标题（22px 欢迎标题等）和特殊元素（文件预览 14px 等）保留原有比例

## 技术栈

- **前端框架**：Vue 3 (Composition API + `<script setup>`)
- **UI 库**：Element Plus（el-aside 组件）
- **构建工具**：Vite
- **样式方案**：内联 `<style>`（非 scoped 全局样式 + scoped 组件样式）

### 关键设计决策

- **手术刀式修改**：每个改动都是单行 CSS 属性变更，不重构、不移动代码块
- **零运行时影响**：纯 CSS 变更，不修改 JS/TS 逻辑，不改变组件行为
- **渐进式层级**：遵循 14→13→12→11 四级递减体系，而不是所有文字等比例放大
- **保留视觉对比**：通过更明显的字号差异强化信息层级，而非扁平化处理

## 设计思路

本次调整属于视觉精调（visual refinement），不改变整体设计风格，而是在现有设计系统基础上进行字体层级规范化。

### 字体层级体系

采用经典排版模度（typographic scale）原则，以 14px 为基数建立清晰层级：

- **L0 - 超大标题**：22px → `.welcome-title`，作为页面视觉锚点
- **L1 - 基础正文**：14px → 消息文本、输入框、预览区，占 80% 阅读内容
- **L2 - UI 控件**：13px → 按钮、标签、搜索框、对话标题、卡片文本
- **L3 - 辅助信息**：12px → 过滤标签、空状态、加载提示、思考过程
- **L4 - 次要元数据**：11px → 时间戳、文件大小、编辑提示（最小可读尺寸）

### 侧栏宽度统一

AI 助手侧栏从 220px 扩展到 240px 后，与控制台侧栏完全一致：

- 标题文字展示更完整，减少省略号截断
- 用户在不同页面间切换时视觉体验一致
- 20px 增量（约 9%）不会挤压聊天区域

### 视觉一致性保障

- 折叠态宽度维持 52px 不变
- 所有过渡动画（transition: width .25s ease）保持不变
- 不修改任何颜色、间距、阴影等其他视觉属性
- 不修改任何非字体/宽度相关的功能逻辑
