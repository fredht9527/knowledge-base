## sanitize-html → DOMPurify 迁移

**问题**：`sanitize-html` 依赖 Node.js 原生模块（`path`/`fs`/`url`/`source-map-js`），Vite 在浏览器兼容模式下将其 externalized，导致运行时报错 "Module has been externalized for browser compatibility"。

**修复**：
- 卸载 `sanitize-html`，安装 `dompurify@^3.4.4`（专为浏览器设计，零 Node 依赖）
- `MarkdownViewer.vue` 和 `HomeChat.vue` 中 `sanitizeHtml()` 替换为 `DOMPurify.sanitize()`
- 配置项从 sanitize-html 的 `allowedTags/allowedAttributes/allowedClasses` 改为 DOMPurify 的 `ALLOWED_TAGS/ALLOWED_ATTR/ALLOW_DATA_ATTR`
- 构建验证通过，6.89s，零错误
